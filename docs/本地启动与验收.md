## 0. 两个 App 可以同时开

**magpie plus 与官版 magpie 现在能共存**（2026-10-27 修好）。两者共用一份配置
`~/.config/magpie/`，所以：

- 账号、密钥、用量历史**只登录一次，两边都能用**；
- 但**网关只有一个**：先启动的持有 `127.0.0.1:3425`，后启动的退化成纯页面
  （日志写 `the gateway ... is served by another magpie`，功能不受影响，只是不接活）；
- 两个窗口同时改设置时，后保存的覆盖先保存的；
- 两边的**余额页都打开**时，会各自拉一个 power-meter sidecar 读同一份 `accounts.json`
  ——数据一致，但平台请求翻倍。只想看余额的话，只开一边的余额页即可。

托盘图标各有一个，互不干扰。

## 1. 一次性准备

### 1.1 编译 power-meter 并装成 sidecar

sidecar 是 power-meter 的**编译产物目录**，magpie 从 `<config>/magpie/powermeter/` 找它。
power-meter 一改代码就要重跑这两步（第 2 步的 rsync 是整棵覆盖）：

```bash
cd ~/DevSpace/power-meter && npm run build
```

```bash
cd ~/DevSpace/magpie+powermeter && make balance-board POWER_METER=~/DevSpace/power-meter
```

`make balance-board` 只覆盖 `dist/` 与 `public/`，**不动**你放在同一目录下的 `.env` 与 `accounts.json`。

### 1.2 编译 fork 的 magpie

```bash
cd ~/DevSpace/magpie+powermeter && make build
```

## 2. 方式 A：浏览器里看（推荐先用这个）

```bash
cd ~/DevSpace/magpie+powermeter && ./magpie web
```

它打印一行 `magpie web on http://127.0.0.1:3435/?k=…`，**必须点带 `?k=` 的完整链接**
（不带 key 会被要求重新登录）。左侧导航「观测」组里第 4 项就是 **余额看板**。

> 若提示 `the gateway on http://127.0.0.1:3425 is served by another magpie`：
> 这是正常的——官版在当网关，fork 只负责页面。要看余额板完全够用。

## 3. 方式 B：真桌面 App（能验托盘）

这个 fork 的 App 叫 **magpie plus**（`make app` 产出 `magpie plus.app`），
与官版 `magpie.app` 是**两个不同的应用**（bundle id `com.a1ether.magpie-plus`），
**可以同时打开，不必先退出官版**。

```bash
cd /Users/a1ether/DevSpace/magpie+powermeter && make app && open "magpie plus.app"
```

- 菜单栏应用名、窗口标题、Mac 的 App 菜单（关于/隐藏/退出）都显示 **magpie plus**。
- 托盘（菜单栏）图标里应有 **余额看板** 一项，点了直接跳到该页。
- 这个 `.app` 是未签名 + 未公证的本地构建；若被 Gatekeeper 拦，右键 → 打开。
- 包内的可执行文件仍叫 `magpie`（`magpie://` 链接和终端里的 `magpie` 都靠它）。

## 4. 打开余额板

**默认是关的，第一次要自己开**：进页面会看到「伴随进程未开启」和「开启伴随进程」按钮，
点一下 → 写入设置 `powerMeter: true` → sidecar 被拉起（约 5–15 秒）→ 状态条从「启动中」变「已刷新」。

> 本次验收期间我已经在你本机把它打开过（`~/.config/magpie/settings.json` 里 `powerMeter: true`），
> 所以直接进页面应该已经是「已刷新」。关掉它也在这个页面上（右上「关闭伴随进程」）。

## 6. 已知不通过 / 未验证（不是 bug）

- **全量 Go 测试**有 11 个用例红，全部在未改动的上游代码里（需要真实 WSL / SOCKS 代理 / Wails 窗口 / 特定环境），已在干净 base 上逐个复现，见 FORK.md §11。
- **全量 GUI 测试**（`internal/gui/tests/` 共 886 个文件）未整套跑过；余额页自己的 40 个用例、品牌/i18n/标题相关的 18 个用例已在 Chromium 与 WebKit 双引擎跑绿。
- **登录 / 移除账号没有对真实账号执行过**（会真向平台发起扫码会话）——这一步留给你。
- **真桌面 App 未点开过**：托盘文案、Mac 的 App 菜单、Finder 里的 `magpie plus` 都只有代码与 `traymenu_test.go` 的四语言单测覆盖。
- 上游 `fitTop` 在 720–910px 之间表头会来回跳（ResizeObserver 自反馈），是上游既有缺陷，未修，见 FORK.md §7。

### 跑 GUI 测试要指定 Playwright

仓库本身不带 `node_modules`。本机有多个 Playwright 安装，**只有 1.62.1 与已下载的 WebKit `webkit-2336` 配套**
（1.57 要 webkit-2227、1.63 要 webkit-2359、1.64 要 webkit-2370，都没装）：

```bash
cd /Users/a1ether/DevSpace/magpie+powermeter && NODE_PATH=~/.npm/_npx/db89d7302a373f10/node_modules node --test internal/gui/tests/balance-board.test.cjs
```

只跑一个引擎用 `BROWSER=chromium` 或 `BROWSER=webkit` 前缀。
