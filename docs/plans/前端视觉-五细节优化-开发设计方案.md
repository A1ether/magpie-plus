# 前端视觉 · 五细节优化（等宽数字 / 同心圆角 / 错开入场 / 平衡换行 / 阴影代替边框）

> 文档类型：开发设计方案
> 关联模块：前端视觉系统（`public/styles.css` + `public/app.js` 渲染层）
> 创建时间：2026-10-23
> 最后更新：2026-10-23
> 当前状态：已完成
> 关联改动文件：`public/styles.css`、`public/app.js`

## 1. 背景与目标

参考抖音教程《5 个小细节让 AI 设计的界面看着更舒服》（费纸张），把其中五条通用细节落到本看板的视觉系统上：

| # | 细节 | 要解决的问题 |
| --- | --- | --- |
| 1 | 等宽数字（tabular figures） | 数字刷新时字形宽度变化导致整块文字抖动、列不对齐 |
| 2 | 同心圆角（concentric radius） | 嵌套块的圆角与外层不平行，视觉上「歪一档」 |
| 3 | 错开入场（staggered entrance） | 首屏一次性「啪」地全出现，缺少节奏与层次 |
| 4 | 平衡标题换行（balanced wrapping） | 窄容器里标题折行后末行只剩一两个字 |
| 5 | 阴影代替边框（shadow instead of border） | 到处 1px 描边显得廉价、边框还占布局宽度 |

Non-Goals：

- 不改变配色、不引入新字体 / 新依赖（继续运行时零第三方依赖）。
- 不重排信息架构、不改任何 API 与数据契约。
- 不引入 JS 动画库；入场动画纯 CSS。

## 2. 现状调研

| 细节 | 现状 | 证据 |
| --- | --- | --- |
| 等宽数字 | 主力数字已用 `font-variant-numeric: tabular-nums`（14 处），但时间、计数、副标题等长尾数字未覆盖 | `public/styles.css:349,453,538,714,749,815,877,1042,1115,1158,1236,1252,1342,1615,1626,2367` |
| 同心圆角 | 外层卡片 `--r-lg: 20px`、内边距 17/18px，内层块却仍是 10px，弧线不平行；弹窗内 `.platform` 14px 也偏大 | `public/styles.css:56-58`（半径）、`871-880`（`.card`）、`1004`（`.usage`）、`1152`（`.lot`）、`1985`（`.platform`） |
| 错开入场 | 只有 `subOpen` / `dialogIn` / `breathe` 三种动画，列表与卡片一次性出现 | `public/styles.css:392-401`、`2010-2016` |
| 平衡标题换行 | 无任何 `text-wrap` 声明 | `grep text-wrap public/styles.css` 无命中 |
| 阴影代替边框 | 主体块一律 `border: 1px solid var(--line)`，hover 靠改 `border-color` | `public/styles.css:678`、`890`、`826`、`1900`、`2043`、`2326` |

可复用的既有能力：`--line` / `--line-strong` 由 `color-mix` 跟随主题（`styles.css:22-24`），`prefers-reduced-motion` 已有全局兜底（`styles.css:2520-2540`），`app.js` 已有统一的 `element()` 构造器与 `replaceChildren()` 渲染入口（`app.js:282-355`、`553-586`、`2136-2157`）。

## 3. 方案设计

数据流不变，只改渲染后的样式层：

1. **等宽数字**：补齐长尾数字（时间线徽标、卡片更新时间、页脚生成时间、平台账号计数、统计提示）为 `tabular-nums`，与既有 14 处口径统一。
2. **同心圆角**：在 `:root` 引入 `--pad-card` / `--r-in-card` 等派生 token，规则固定为 `内层半径 = 外层半径 − 内边距`，并用 `max(6px, …)` 兜底避免内层过方；卡片内所有内嵌块（用量块、批次行、账号行、密钥块、折叠按钮、备注块）与弹窗内平台分组统一改用该 token。
3. **错开入场**：`app.js` 在三个容器（`.summary`、`.grid`、`.timeline`）首次渲染时打 `data-enter="stagger"` 并给子项写 `--i`，CSS 用 `animation-delay: calc(var(--i) * 45ms)`；**只在首次渲染生效**，自动刷新 / 手动刷新重渲染时为 `data-enter="instant"`，不重放动画。
4. **平衡标题换行**：标题类 `text-wrap: balance`，正文类 `text-wrap: pretty`。
5. **阴影代替边框**：外层表面块去 `border`，改用 `box-shadow: 0 0 0 1px <ring色>` 画 1px 轮廓 + `inset 0 1px 0` 顶部高光 + 两级环境阴影；hover 与告警态改为切换 `--ring-color` / `--elev` 两个变量，不再改 `border-color`。输入框 / 按钮的描边保留（它们表达可操作性，不是「块」）。

## 4. 接口设计

无新增 / 变更 HTTP API，无 `ProviderAdapter` 契约变更。

前端约定的内部契约（仅供样式与渲染协同）：

| 名称 | 载体 | 含义 |
| --- | --- | --- |
| `data-enter="stagger" \| "instant"` | `.summary` / `.grid` / `.timeline` | 该容器本轮渲染是否参与错开入场 |
| `--i` | 上述容器的直接子元素内联样式 | 入场序号，用于计算 `animation-delay` |
| `--ring-color` / `--elev` | 表面块 | 1px 轮廓色与阴影层级，hover / 告警态只改这两个变量 |

## 5. 数据模型

无 `types.ts` 契约变更，无 `accounts.json` / `.env` 变更。

`styles.css` 新增 token：

| token | 值 | 用途 |
| --- | --- | --- |
| `--pad-card` / `--pad-card-x` | `17px` / `18px` | 卡片内边距，同心圆角计算依据 |
| `--r-in-card` | `max(6px, calc(var(--r-lg) - var(--pad-card-x)))` | 卡片内嵌块半径 |
| `--r-in-md` | `max(6px, calc(var(--r-md) - 11px))` | 中等块内嵌半径 |
| `--hi` | `inset 0 1px 0 color-mix(...)` | 顶部 1px 高光，替代边框带来的「厚度」 |
| `--elev-1` / `--elev-2` | 两级环境阴影 | 静置 / hover 抬升 |
| `--shadow-1` / `--shadow-2` | `var(--elev-1)` / `var(--elev-2)` | 兼容既有引用 |

## 6. 影响面评估

| 影响对象 | 说明 |
| --- | --- |
| 汇总统计 `.stat` | 去边框改阴影 ring，hover 抬升 2px；删除冗余 `::after` 顶部发丝线（改由 `--hi` 承担） |
| 平台卡片 `.card` | 同上；`data-urgency` 告警态由 `border-color` 改为 `--ring-color` |
| 工具条 / 面板 / 告警条 / 弹窗 / 命令面板 / 停靠栏 / 收起按钮 / 开关 / 平台分组 | 去边框改 ring，hover 行为不变 |
| 卡片内嵌块 | 半径由 10px 收敛到同心值（6px），弧线与卡片外沿平行 |
| 首次渲染 | 统计、卡片、时间线错开 45ms 入场，总时长上限约 0.4s + 0.45s |
| 自动刷新（5 分钟） | 不重放入场动画，避免周期性闪动 |
| 无 JS 环境 / 减少动效偏好 | 动画被 `prefers-reduced-motion` 全局压掉，布局不受影响 |
| 既有 API 消费方 | 无（纯样式层） |

## 7. 风险与备选方案

| 风险 | 处理 |
| --- | --- |
| 去掉真边框后，部分浏览器 `box-shadow` ring 在 `overflow: hidden` + `backdrop-filter` 上可能被裁 | ring 由元素自身 `box-shadow` 绘制，不参与裁剪；若出现裁切，回退为 `outline: 1px solid var(--line); outline-offset: -1px` |
| 入场动画拖慢首屏感知 | 位移仅 10px、时长 0.46s、延迟 45ms/项；刷新不重放 |
| 同心圆角收敛后内层块偏方 | `max(6px, …)` 兜底，最小保留 6px |
| hover 依赖 `border-color` 过渡的旧规则漏改，导致 hover 无反馈 | 改动范围内逐条核对 `border-color` 出现位置，表面块全部改为 `--ring-color` |

被否决的备选：用 `outline` 全局替代边框 —— 圆角跟随性差且与 `:focus-visible` 冲突；用 JS 逐帧控制入场 —— 违背零依赖与静态检查原则。
